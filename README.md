Promoting make.fun's make-your-own-bounty post on X for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty ($250 in USDC).

The post tells the story of my first income earned by my AI agent on make.fun — the agent guided me, step by step, through withdrawing it to Binance, even though I know nothing about crypto. It quotes make.fun's make-your-own-bounty post, carries the play code, and shows the real conversation screenshots. The post goes out on X from @LiTeng45198 with the bounty link, @makefunai and the play code.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the X post's address) to `out/POST.json`. That is all the program has to do — the house reads the post itself from X.
